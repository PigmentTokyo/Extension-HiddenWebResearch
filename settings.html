SearXNG

当前 SearXNG 路径只使用搜索结果标题、URL、日期和摘要，不会像原生搜索工具那样继续读取完整网页；它属于摘要级研究。

SerpAPI Google Search

复用原版 SillyTavern 内置的 SerpAPI 密钥槽与基础搜索路由。这里保存的新 Key 也会成为酒馆 WebSearch 等功能使用的当前共享 Key；每次只请求一页。

Tavily AI Search

复用原版 SillyTavern 的 Tavily 搜索路由与当前用户的共享密钥槽。这里保存或删除 Key 也会影响酒馆 WebSearch 等其他使用者。P1G搜只采用带有效 HTTP(S) URL 的搜索结果，不请求图片，也不会把 Tavily 顶层 answer 当成可独立引用的证据。

Serper Google Search

复用原版 SillyTavern 的 Serper 搜索路由与当前用户的共享密钥槽。这里保存或删除 Key 也会影响酒馆 WebSearch 等其他使用者；每条规划查询只请求一页，并只采用带有效 HTTP(S) URL 的结果。

KoboldCpp WebSearch

不另存 URL 或 Key，直接继承 SillyTavern 当前 Text Completion → KoboldCpp 的服务器 URL。需要 KoboldCpp 1.81.1 或更新版本，并以 --websearch 启动；网页检索由该 KoboldCpp 实例完成，主模型仍按当前酒馆连接回答。

Extras API（已废弃）

SillyTavern Extras 已停止维护；这里只保留与既有安装的兼容。必须先在酒馆配置可用的 Extras API，并启用其 websearch 模块。新安装建议优先使用 SearXNG、Tavily、Serper 或其他受支持来源。
Extras 返回聚合正文与候选链接，无法可靠证明每一条事实对应哪一个 URL。选择此来源时，P1G搜强制使用中性聚合研究包，不构造隐藏工具结果；候选链接只供模型核对方向，模型不得伪造逐条引用或宣称它们分别支持某项事实。

Selenium Plugin

此来源不是纯前端能力：必须在 SillyTavern 服务器安装并启用 WebSearch Selenium server plugin。其他搜索来源不依赖该插件，也不需要修改酒馆核心文件。
Selenium Plugin 返回聚合正文与候选链接，无法可靠证明每一条事实对应哪一个 URL。选择此来源时，P1G搜强制使用中性聚合研究包，不构造隐藏工具结果；候选链接只供模型核对方向，模型不得伪造逐条引用或宣称它们分别支持某项事实。

兼容性、隐私与技术说明版本与数据边界

兼容 SillyTavern 1.13.3 及以上版本（已验证 1.13.3–1.18.x）。直填多组副 API Key 需要 1.18.0+；旧版请使用 Connection Profile。

搜索资料只临时进入本轮模型请求，不写入聊天、附件、Data Bank、LocalStorage 或 IndexedDB；搜索词及必要上下文会发送给你选择的搜索服务和规划 API。

SerpAPI、Tavily、Serper 与直连规划 Key 存在 SillyTavern 服务端 secrets 中。插件调试日志不打印搜索正文，但原版酒馆、外部来源或可选组件可能按各自策略记录请求。

自动注入会优先使用隐藏工具历史；协议不兼容时改用中性隐藏研究包。Extras 与 Selenium 只能提供未逐条归因的聚合资料，因此始终使用研究包。
